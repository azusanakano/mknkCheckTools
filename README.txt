■ 起動方法
1. ZIPファイルを右クリックし、「すべて展開」を選びます。
2. 展開した mknkCheckTools_v1.2.4 フォルダーを開きます。
3. index.html をダブルクリックします。
4. メニューの「液晶チェック」「キーボードチェック」を選ぶと、新しいタブで開きます。
   「スピーカーテスト」では音声を再生できます。

インストール・管理者権限・インターネット接続は不要です。
HTMLを開けるデスクトップブラウザーで使用します。
デスクトップ版の Edge / Chrome / Firefox などを利用してください。
全画面や特殊キーの挙動は環境によって異なります。
ファイルのプレビュー画面ではなく、ブラウザーでHTMLを開いてください。
移動やUSBメモリーへのコピーは、フォルダー全体で行ってください。

■ 液晶チェック
黒 / 白 / 赤 / 緑 / 青 / 黄変 / ムラ / シマシマの8モードを搭載しています。

画面クリック・→・Space・Enter: 次のモード
←: 前のモード
1～6: 黒 / 白 / 赤 / 緑 / 青 / 黄変を直接選択
M: ムラ
S: シマシマ
A: 自動切替の開始 / 停止（1.8秒ごと）
H: 操作パネルを隠す / 表示する
F: 全画面表示の切替
Esc: 全画面解除、自動切替の停止（ブラウザーの処理が優先される場合あり）

右上の「メニューへ戻る」で選択画面に戻ります。
操作パネルが見えない場合は、Hキーで再表示してください。
全画面表示が利用できない場合は、ブラウザーの全画面機能（F11など）を使用してください。
操作ボタンはTabキーで選び、Enter / Spaceで実行できます。

ムラ・黄変モードは、元ファイルに含まれる模様付きの表示パターンです。
画面全体の均一性は、白や他の単色表示でも比較して目視で判断してください。

■ キーボードチェック
入力テストエリアをクリックして、調べたいキーを押します。
key / code、keydown / keypress / keyup、Shift / Ctrl / Alt / Metaの状態を表示します。
左右の区別は code（例: ShiftLeft / ShiftRight）で確認できます。
イベントログは、端末のローカル日時（ミリ秒まで）と1始まりの連番を付け、最新の操作を上に表示します。
1件ごとに空行で区切り、押下（keydown）・文字キー（keypress）・解放（keyup）を日本語で表示します。
キーと物理キー（code）、位置（標準・左・右・テンキー）、押されている修飾キー、長押し反復の有無を記録します。
スペースは「スペース」と明記し、診断用のlocationの数値、keyCode、which、isTrustedも残します。
修飾キー欄にないShift / Ctrl / Alt / Metaは押されていない状態です。
keypressは文字キーのイベントであり、IMEなどによる文字入力の確定を示すものではありません。
発生元の「ブラウザー / スクリプト」はisTrustedの値を示し、物理キー入力を保証するものではありません。
keyupだけが通知されるキーや疑似イベントも記録します。
「クリア」でログと連番をリセットし、「ダウンロード」で同じ読みやすい形式のテキストファイル
（UTF-8 BOM付き、改行はCRLF）を保存できます。画面上の長い行は欄の幅に合わせて折り返します。
イベントログ欄は読み取り専用です。欄内のキー操作は記録せず、Ctrl+Aで全選択、
Ctrl+Cでコピー、矢印キーなどで選択範囲の移動ができます。

「特殊キーをブロック」は、特殊キーの既定動作を抑える機能です。
スイッチがオン（青）のときは「ブロック中」、オフ（灰色）のときは「ブロック解除」です。
入力テスト中にTab・Enter・Backspaceなどが通常どおり動かない場合は、
スイッチをオフにして「ブロック解除」にしてください。
このフィルタは、OSの操作やすべてのブラウザーショートカットを抑止するものではありません。
PrintScreen・Windowsキーなどは、OSや機器によりイベントが届かない場合があります。
記録されないことだけでは、キーの故障とは断定できません。

左上の「メニューへ戻る」で選択画面に戻ります。
画面を閉じたり移動したりする前に、必要なログはダウンロードしてください。
ツールから外部へのデータ送信や、自動でのログ保存は行いません。

■ v1.2.3: 添付された倍速版MP3へ更新
index.htmlの「スピーカーテスト」で、左 → 右 → 中央の順に再生します。
「① 左から再生」を押すと、約18秒のテスト音声を最初から再生します。
「② 右から再生」「③ 中央から再生」で、それぞれの音声の直前へ移動できます。
各ボタンは指定位置から最後まで再生します。
一時停止はプレーヤーのボタン、先頭へ戻すには「停止して先頭へ」を使用します。
再生はボタンを押したときに開始します。自動再生はしません。

使用音源: TEST_TONE_left_right_center_2x(1).mp3
再生用: media/TEST_TONE_left_right_center_2x.mp3
形式: MP3 / 48,000 Hz / 320 kbps / ステレオ2ch
長さ: 約18秒（復号後17.980979秒、MP3コンテナーの表示値18.024秒）
添付MP3はファイル名のみ整理し、全バイトをそのままコピーしています。
音量・左右チャンネル・音質・再生速度を変更していません。
すでに倍速処理された音源のため、プレーヤーは1倍速で再生します。
プレーヤーの初期音量は従来どおり100%です。

再生位置の目安: 左0秒 / 右5.5秒 / 中央11秒
右・中央は発音前の静かな移行部分から再生します。
中央の区間は左右から音が出ますが、左右の波形は完全一致ではありません。
これは添付音源の構成を保持したものです。
左右の聞こえ方は、端末のモノラル設定やスピーカーの配置にも依存します。

WAV保存用: media/TEST_TONE_left_right_center_2x.wav
形式: リニアPCM WAV / 48,000 Hz / 16 bit / ステレオ2ch
同じMP3を復号して作成したWAVです。音質はMP3に由来します。
インターネット接続は不要です。mediaフォルダーごとコピーしてください。
